# Предсказания моделей

Каждый `.npy` здесь — одномерный массив меток 0–8 в порядке строк `clean_data.parquet` (180 901 строка). Номера классов разных моделей могут не совпадать; перед голосованием их нужно выровнять.

`pred_nikita_physical_v1.npy` получен моделью `src/physical_model.py`, обученной на разметке Юли v11. Это зависимый от Юли эксперимент, а не независимое подтверждение операций и не официальный Score. Остальные `pred_cap_*.npy` — варианты капитана; `pred_dania_vote.npy` — результат голосования Дани. Их код и результаты следует сопоставлять по записи в [журнале](../report/TEAM_LOG.md).
