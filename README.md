# Хакатон «Газпром нефть» × ИТМО 2026
Сегментация многомерных временных рядов буровой установки (180 000 строк, 9 классов без разметки).

## Метрика
`Score = 0.4 * ARI + 0.4 * F1_macro (Hungarian) + 0.2 * F1_boundary`

## Правила команды
- Сырые данные и `features_*.parquet` храним на общем Google Диске (в Git не заливаем).
- Каждый ведёт свои ноутбуки в папке `notebooks/<имя>/`.
- Предсказания сохраняем в `preds/pred_<имя>_<модель>.npy` (1D-массив `int`, длина 180 000, метки `0..8`).
- Перед загрузкой в Google-форму проверяем файл через `src/validate.py`.
