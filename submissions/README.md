# Файлы для отправки

Здесь хранятся только CSV, которые команда действительно проверила и решила отправить. Формат: `ID,operation`, 180 901 строк в порядке исходных ID, метки 0–8 без пропусков.

Для каждой отправки запишите имя файла и официальный Score в [`report/TEAM_LOG.md`](../report/TEAM_LOG.md). Рабочие массивы `.npy` лежат в [`preds/`](../preds/).
