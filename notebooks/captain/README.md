# Ноутбук капитана

`exploration.ipynb` — исследовательский Colab-ноутбук по исходным данным и вариантам кластеризации. Для запуска ему нужны входные данные в среде Colab; результаты уже выполненных ячеек сохранены в самом ноутбуке.

Предсказания капитана лежат в [`preds/`](../../preds/). Проверенные CSV для отправки следует класть в [`submissions/`](../../submissions/), записывая соответствующий результат в [журнал команды](../../report/TEAM_LOG.md).
